Dressage Competition Support

Dressage Test Sheet PDF 馬場馬術のジャッジペーパーPDFを、入力から一気に作成。

入力した競技会・競技・選手の情報から、審判用のジャッジペーパー（採点用紙）PDFを作成できるWindows用デスクトップアプリです。 競技会の情報はひとつの画面で管理でき、インストール不要、データはお使いのPC内に保存されます。

Dressage Test Sheet PDF for Windows

インストール不要のportable版です。ダウンロードした .exe をそのまま実行すると起動します。

Dressage Test Sheet PDF 1.0.0 をダウンロード Windows 64bit ／ portable版 ↓

ファイル名: DressageTestSheetPDF-1.0.0.exe（約95MB）
配布元: GitHub Releases

動作環境と配布形態

  • Windows 10 / 11（64bit）
  • インストール不要のportable版
  • 管理者権限は不要
  • PDF出力・課目テンプレートは同梱、オフラインで動作
  • データはアプリ内（お使いのPC）に保存

ダウンロード後の起動手順

  1. ダウンロードした DressageTestSheetPDF-1.0.0.exe を任意のフォルダーに置きます（デスクトップ等でも可）。
  2. exeファイルをダブルクリックします。少し待つとアプリのウィンドウが開きます。
  3. 「WindowsによってPCが保護されました」と表示された場合は、［詳細情報］ をクリックし、続いて ［実行］ を押します（署名なしアプリのため表示されます）。
  4. 2回目以降はこの警告は出ません。アンインストールは、置いたexeファイルを削除するだけです。

How To Use

画面付きで使い方を解説します

「画面の見かた」→「競技をつくる」→「選手を入力する」→「保存」→「読み込み」→「PDF出力」の順に読み進められます。

1 画面の見かた

3つのエリアで構成されています

画面は「競技会共通情報（上部）」「競技情報一覧（左）」「詳細エリア（右）」の3つに分かれています。 左の一覧から競技を1つ選ぶと、右側にその競技の「競技情報」と「選手情報」が表示されます。

  • 上部：競技会共通情報 ― 競技会名・実施日・競技場名と、新規／読込／保存、バックアップの書出／読込ボタン。
  • 左：競技情報一覧 ― 登録した競技が「第○競技 → 競技名 → 課目」の順に並びます。各行右の「−」で削除。
  • 右：詳細エリア ― 左が競技情報（固定幅）、右が選手情報。競技未選択のときは案内メッセージが出ます。
ウィンドウの初期サイズは1600×920です。画面が狭いと選手情報に横スクロールが出ることがあります。

2 競技会と競技をつくる

新規作成して、競技を追加していきます

上部の ［新規］ で競技会を初期化し、競技会名・実施日・競技場名を入力します。 競技会名は保存に必須です。続いて左下の ［+ 競技追加］ で競技を1つずつ増やしていきます。

  • ［新規］ を押す ― 競技会名が入っていれば自動保存してから初期化します。第1競技の空欄が1つ用意されます。
  • 競技会共通情報に 競技会名・実施日・競技場名 を入力します。
  • ［+ 競技追加］ で競技を追加。番号は自動採番されます。まとめて用意するときは ［競技数指定］。
  • 右の競技情報で 競技課目 を選ぶと、競技名に課目名が自動で入ります（あとから変更可）。
  • 担当審判員 の E / H / C / M / B に、その席の審判名を入力します（使う席だけでOK）。
競技番号を途中で変更すると「後続の競技番号も通し番号にしますか？」と確認されます。「はい」で以降の競技が連番に振り直され、選手情報も一緒に移動します。

3 選手情報を入力する

1行ずつ、または表計算ソフトからまとめて貼り付け

選手情報は競技ごとに管理します。列は 出番 / WD / 選手名 / 会員番号 / 馬匹名 / 馬登録番号 / 所属。 ExcelやGoogleスプレッドシートでコピーした範囲を、開始セルにそのまま貼り付け（Ctrl+V）できます。

  • ［+ 選手追加］ で末尾に1行追加。行右の 「+」 はその行の1つ下に追加、「−」 は行の削除です。
  • 必要な人数が決まっていれば ［競技人数指定］ で一括作成。既存の入力は保持されます。
  • 表計算ソフトの範囲をコピーし、貼り付け先の先頭セルで貼り付けると、タブ区切り＝列・改行＝行として反映されます。行数が足りなければ自動で増えます。
  • 棄権などで出力対象から外す選手は WD にチェック。行がグレーになり、人数カウントとPDF出力の対象外になります。
  • 出番を手動で変えて入力欄を離れると「後続を通し番号にしますか？」と確認されます。
画面右上の 「登録数: ○人」 と出力ボタンの人数は「WDでなく、選手名が入っている行数」で数えます。 PDF出力にはさらに 馬匹名・所属 も必要なため、表示人数と実際の出力枚数が違う場合があります。 会員番号・馬登録番号はPDFには使われません。

4 保存のしくみ

自動保存されます。移行・保管はバックアップで

入力中の内容は常に「作業中データ」として下書き保存されます。さらに 競技会名が入力されていれば、 入力欄からフォーカスが外れたときや、行の追加・削除・件数指定などの操作時に、 名前付きの保存済み競技会へも自動保存されます（「自動保存しました」と一時表示）。

  • 手動で確定したいときは上部の ［保存］。競技会名が空だと「競技会名を入力してください」と表示され、保存済み一覧には追加されません。
  • 同じ競技会名のデータは 上書き、新しい名前なら一覧の末尾に 追加 されます。
  • 別のPCへ移したいときや長期保管したいときは、バックアップ ［書出］ でJSONファイルを保存します（競技会・選手・保存済み一覧をすべて含む）。
  • 復元は バックアップ ［読込］ からJSONファイルを選択。現在の全データを置き換える確認が出ます。
データはクラウドではなく 使用中のPC内 に保存されます。PCの入れ替えや初期化の前には、必ずバックアップを書き出してください。

5 保存済み競技会を読み込む

起動時の「前回の続き」と、［読込］からの選択

前回の作業データが残っている状態でアプリを起動すると、「前回の続きを行いますか？」 と確認されます。 「はい」で前回の続きから、「いいえ」で新規作成の状態から始まります。 過去に名前を付けて保存した競技会は、上部の ［読込］ からいつでも呼び出せます。

  • 起動時のポップアップで ［はい］ ＝前回の続き、［いいえ］ ＝新規作成。
  • 上部 ［読込］ を押すと、保存済み競技会の一覧（競技会名／実施日／競技場名／競技数）が表示されます。
  • 読み込みたい競技会を選んで ［読み込む］、またはその行を ダブルクリック。
  • 不要な保存データは、選択して ［削除］（確認あり）。
［読込］を押した時点で、競技会名が入っていれば現在の内容が先に自動保存されます。競技会名が未入力で未保存の変更があるときだけ、破棄の確認が出ます。

6 ジャッジペーパーPDFを出力する

競技情報の［ペーパー出力］ボタンから作成します

競技を選択し、競技情報ペイン下部の ［ペーパー出力 (○人)］ を押すと、その競技のジャッジペーパーPDFが作られてダウンロードされます。 1選手につき、審判名が入力されている席（E / H / C / M / B）ごとに1枚出力されます。

  • 出力対象は「WDでなく、選手名・馬匹名・所属がすべて入力されている」選手です。
  • 出力順は 席ごと（E→H→C→M→B）→ 出番順。審判名が空の席は出力されません。
  • 予備印刷枚数（各地点） に1以上を入れると、各席の先頭に白紙テンプレートをその枚数だけ追加します（書き損じ用）。
  • A4のジャッジペーパーを2枚ずつ A3横1枚に面付け した状態で出力されます。
  • ファイル名は 実施日_競技会名_競技番号_課目名_競技名.pdf。未入力の項目は「未設定」になります。
ボタンの人数（選手名のみで判定）と実際のPDF枚数（馬匹名・所属まで必要）は一致しないことがあります。 出力されない選手がいるときは、馬匹名・所属の入力漏れを確認してください。
出力後は必ず内容をご確認ください。 本アプリは製品レベルの検証を行っていません。印刷・配布の前に、PDFの選手名・馬匹名・所属・審判名・課目、席とページの対応、枚数などをご自身で必ず点検してください。 出力結果の正確性は保証されず、利用によって生じた不具合について作者は責任を負いません。

FAQ

よくある質問

起動時に「WindowsによってPCが保護されました」と出ます

署名のない個人配布アプリのため表示されます。［詳細情報］→［実行］で起動できます。2回目以降は表示されません。

インストールは必要ですか？

不要です。ダウンロードしたexeファイルをダブルクリックするだけで起動します。削除はexeを消すだけです。

入力したデータはどこに保存されますか？

お使いのPCのアプリ内領域に保存されます。クラウド同期はありません。別PCへ移すときはバックアップの［書出］でJSONファイルを保存し、移行先で［読込］してください。

インターネットに接続していなくても使えますか？

使えます。課目テンプレートPDF・フォントはアプリに同梱されており、PDF出力もオフラインで動作します。

「登録数」とPDFの出力枚数が合いません

登録数は「選手名が入っている行」で数えますが、PDF出力には馬匹名・所属も必要です。出力されない選手は、その2項目の入力漏れがないか確認してください。会員番号・馬登録番号はPDFには使いません。

対応している課目は？

第1〜第5課目（A〜E）、セントジョージ、インター1・2、グランプリ、ヤング団体、ジュニア団体の計18課目です。競技課目のプルダウンから選択します。

出力されたPDFはそのまま使って大丈夫ですか？

本アプリは製品レベルの検証を行っていない個人開発ツールです。出力されたPDFは、印刷・配布の前に必ず内容（選手名・馬匹名・所属・審判名・課目、席とページの対応、枚数など）をご自身でご確認ください。出力結果の正確性は保証されず、利用によって生じた損害について作者は責任を負いません。
